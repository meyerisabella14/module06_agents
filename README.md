## Pilates Studio Assistant

I created a Pilates studio assistant that helps customers check available class times. The assistant uses a separate schedule tool to find classes on Monday, Wednesday, and Friday. It is a mock assistant because it uses keyword rules instead of a real AI model or live scheduling system. Booking and cancellation requests are sent to the front desk because the assistant cannot change reservations. If this assistant used real customer data, private booking information could accidentally be shared with the wrong person.
